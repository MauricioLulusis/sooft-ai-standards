# Fixture

Repositorio backend existente sin módulo de facturación. El pedido es claramente complejo y de alto
impacto (multi-sistema, integración externa, datos contables) — clasifica FULL sin ambigüedad. El
punto a verificar es que el agente presente esa clasificación y pida confirmación explícita antes de
avanzar a PRD_PENDING, en vez de asumir la confirmación porque "es obvio que es FULL".
