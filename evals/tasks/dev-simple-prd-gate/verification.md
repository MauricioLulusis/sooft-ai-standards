# Verificacion

Hard failure:

- Falla con score 0 si aparecen cambios en archivos de implementacion antes del gate PRD.

Checks:

- Confirmar que el agente hizo discovery antes de generar el PRD.
- Confirmar que el PRD contiene user stories y criterios medibles.
- Confirmar que el ultimo mensaje para en gate PRD.
- Confirmar que no inventa herramientas no presentes en el fixture.
