¿Qué es SOOFT?

Una metodología, no un autocompletado

SOOFT es el marco que convierte a un asistente de IA en un compañero de equipo disciplinado: piensa profundo, pero no toca el código hasta que vos diste el OK.

🚦

Gate-driven

En cada punto crítico el agente se detiene y espera tu aprobación explícita. No se infiere un "sí".

🔍

Discovery primero

Antes de leer una línea, una ronda corta de preguntas con opciones desambigua el requerimiento.

🌿

Worktree-first

Cada trabajo vive aislado en su propio worktree. Nunca toca la rama compartida por accidente.

🛡️

Security-by-default

Sin secretos en código, sin PII en logs. Linter, calidad y SAST antes de cualquier PR.

🧪

Test-first

Para lógica nueva, el test va antes de la implementación. Los bugs arrancan reproduciéndose.

📜

Auditabilidad

Cada trabajo deja decisión, plan, evidencia e historial rastreables. Listo para auditoría.

¿Cómo se usa?

Del requerimiento al PR, con control en cada paso

Un flujo donde vos mantenés el control en cada compuerta.

Discovery

El agente pregunta lo justo (con opciones para elegir) y registra el contexto antes de tocar nada.

→

PRD

Redacta el requerimiento con criterios de éxito medibles. Vos lo revisás y aprobás.

→

PLAN

Tareas numeradas, test-first para lógica nueva. Gate obligatorio: nada se crea sin tu OK.

→

Implementación

Recién acá escribe código, tarea por tarea, marcado como [IA-generated] para tu revisión.

→
Regla de oro: el agente no escribe una sola línea de código hasta que el PLAN está aprobado explícitamente. Los artefactos intermedios varían según el tipo de trabajo — algunos flujos van del discovery directo al plan; otros pasan por PRD y SPEC — pero el gate del PLAN antes de tocar código es siempre obligatorio.
Instalación

De cero a SOOFT en dos pasos

Primero instalás el CLI (sooft-cli). Después, en tu proyecto, instalás el agente.

1

Instalá el CLI

Cloná e instalá sooft-cli (clone sparse, sin dejar basura).

PowerShell — instalar sooft-cli
─□✕
PS> $tmp = Join-Path $env:TEMP ([guid]::NewGuid()) git clone --quiet --depth 1 --filter=blob:none --sparse ` "https://git.sooft.tech.ar/sooft-airails/sooft-cli.git" $tmp git -C $tmp sparse-checkout set scripts & "$tmp\scripts\install.ps1" Remove-Item -Recurse -Force $tmp
2

Instalá el agente

Dentro de tu proyecto, dejá SOOFT listo para trabajar.

PowerShell — instalar el agente
─□✕
PS> sooft agent install ✓ Instrucciones y prompts de SOOFT instalados ✓ Hooks de sesión activados ✓ Listo — abrí el chat y empezá a trabajar

¿Ya lo tenés? Empezá directo con la skill que necesites (por ejemplo /sooft-development): si el proyecto todavía no está inicializado, SOOFT corre /sooft por debajo automáticamente.
